# 用智能体辅助自学

智能体可以解释结构、起草公式、转换 CSV 为表格、帮助定位错误。使用它之后，仍能指出修改位置、预测结果并检查本次构建输出，是本工具的练习方式。不要求背诵命令或完全手写代码。

## 给它可核对的材料

有本地环境时，先运行 `python tools/lab.py check XX`。本次 `_build/` 目录中的 `ai-review-prompt.txt` 已包含任务、核验项目、实际命令、日志末尾、源码和 PDF 文本摘录；HTML 报告也可复制这份内容。按需要补充 `check-report.json`、相关源码、完整日志和实际 PDF；离线手册另有各关专用请求可复制。报告中的路径只是位置说明，不能让无法访问你电脑的模型自动读到文件，需自行附上相应材料。

生成的证据请求有长度限制，部分源码和日志会截断或未附；模型需要更多内容时，提供相应原文件。PDF 文本摘录只能支持文字与部分数值核对，无法证明图片比例、遮挡、浮动位置或版式正确。`pdftotext` 或 `pdfinfo` 缺失时，相关证据会标为无法取得，不能让模型补造。

使用在线平台时，提供从该平台下载的当前源码、刚生成的 PDF 和完整编译日志，并说明主文件、编译器、是否执行了完整文献链。没有运行本地检查器就注明“无本地自动报告”。不要用旧 PDF 或一张“编译成功”的截屏替代全部上下文。

## 每轮只推进一个具体问题

1. 请智能体先引用材料里的文件、行号、日志或 PDF 页码，说明已看到什么、缺少什么。
2. 先自己预测一处修改会怎样影响结果，再请求局部提示。
3. 自己试改，重新构建或运行 `check`，用新证据判断修改是否奏效。
4. 完成页面理解题和 PDF 自查。把仍有疑问的项目保留为未确认。

通用请求：

> 请根据我提供的本关材料帮助排错。先列出真实证据和缺失信息，再解释一个问题并给最小修改提示，让我先试改。明确区分“你实际运行或看到了什么”和“你推测会怎样”。没有日志不能声称构建成功，没有查看 PDF 不能声称版式、字形或匿名正确。不要虚构命令执行、截图、文献条目或核验结果。最后给我一个需要预测后验证的小变式，不要仅凭你的认可判定完成。

## 表格与公式

> 把这份 CSV 转成 booktabs 三线表，保留方法名、数值、单位和小数位数。列出需要的宏包，指出每一列对应的数据来源。请让我逐格对照数据；若要重算指标，单独说明计算过程与结果，不把改写公式当作自动更新静态表格。

公式含义、括号范围、上下标、单位与数据仍需核对。真实文献元数据应来自可核对的来源，不能把模型生成的条目直接当来源。

## 如何记录结果

本地报告导入页展示自动检查结果，主关进度只采用 `check_scope='lab'` 的完整报告；支线构建后需重新运行主入口的 `check` 再导入。AI 辅助路线记录模型给出的结论、对应证据和未确认事项，并与自动核验状态分开显示。AI 的认可不生成 `pass`，也不代表已经掌握。`REPORT.md` 可作为个人笔记，不需要写给教师或复制全部聊天记录。

本地检查器不需要联网，也不会上传源码。手册中的复制请求不会自动调用模型；由你选择工具并提供材料。
