# 从教学模板迁移到真实论文模板

Lab 06 的 labpaper.cls 用于练习读取接口与保留模板责任，不冒充 SJTUThesis。thesis/main.tex 用 ctexbook 提供无额外学校依赖的结构实验。

## 本地实际操作

```text
python tools/lab.py build 06 --entry thesis/main.tex
```

这份报告只核对支线入口的构建与日志。它也会更新 `reports/latest-06.json`；完成支线后，重新运行 `python tools/lab.py check 06` 再导入报告。主关进度只采用 `check_scope='lab'` 的完整核验报告，不能用支线构建成功替代主文档核验。

将 thesis/main.tex 中中文与英文摘要改为自己的摘要；将定理名称由“定理”改为“零误差性质”；在附录中解释六条观测是合成数据。重新编译，观察前置部分的罗马页码、正文的阿拉伯页码、附录的字母编号。frontmatter/mainmatter/backmatter 是 book 类结构，不能随意粘到 article 中。

## 官方模板阅读任务（视频专有部分）

打开 [SJTUThesis](https://github.com/sjtug/SJTUThesis) 的 README 与同一版本用户手册。记录自己查看的版本/提交日期和文件位置。课程附带的 `sources/lecture/sjtuthesis.tex` 与 `newversion.tex` 是 2023 讲稿原文，用于历史对照，不作为 2026 年接口保证。

|讲稿主题|你要定位的入口|写入 REPORT 的证据|
|---|---|---|
|获取模板与构建|Release/源码/在线模板，README 的主文档和构建方式|模板版本、主文件、引擎、后端|
|文档类选项|学位类型、语言、单双面等类选项|找到的实际选项及手册小节|
|字体配置|西文字体、中文字体的模板配置|当前环境可用的字体集；不可用时的替代依据|
|数学样式|数学字体、积分号与希腊字母等风格配置|标出模板管理位置，不混加冲突包|
|sjtusetup|题名、作者、导师、学科、日期、关键词等信息|至少三个字段的位置与其输出页|
|版权页|模板生成的声明或插入扫描件的接口|位置与要求；练习中无需真实签名|
|论文组成|双语封面/摘要、目录、图表目录、正文、附录、成果、致谢|分别由主文档哪一段组织|
|定理环境|模板提供或文档声明的 theorem/proof|一处定义或使用位置|
|参考文献|biblatex 的样式、数据库和输出位置|后端、样式、数据库文件|
|版本迁移|变更说明及旧字段映射|一个旧字段为什么不能原样复制|

离线时可先在已缓存讲稿中完成“历史入口定位”，在报告注明“当前版本未核验”；不要虚构自己下载或编译过官方模板。本包核验针对教学模板，若需要真实学校提交，必须另外按其官方规范核验。

## 2023 讲稿的迁移卡

讲稿 newversion.tex 描述当时 SJTUThesis v1.x → v2.0 的变化，包括旧 `assisupervisor` 到 `assoc-supervisor`，`type=course` 的移除与课程论文类选择，以及样式配置入口的变化。练习：在缓存原文找到上述字段，说明为什么“视频里的旧命令”可能不适合新模板。这些是历史变更，不是当前最新发布说明。

讲稿还概览 SJTUBeamer、SJTUReport、SJTUArticle。辨认用途即可：演示文稿、报告、小论文分别需要不同文档类。无需为了练论文而额外做一份幻灯片。

## 交付与转换

正式提交先看对方要 PDF、LaTeX 源码还是 Word。不要保证复杂 LaTeX 可以无损转换为 Word；公式、引用、图表和模板版式需要重新检查。统计字数可使用 TeXcount，但注释、数学和中文分词口径应按提交要求说明。构建、清理和字数统计属于不同操作，不把“清理全部”当成日常排错按钮。
