# 自学与核验

每关都可以自己完成：修改工程，取得真实输出，查看核验信息，回答理解题，再检查 PDF。任务书、分级提示和参考解都可随时查看，不需要等待教师或他人签字。

## 路线一：本地自动核验

在项目根目录运行，以下以 Lab 03 为例：

```text
python tools/lab.py doctor
python tools/lab.py start 03
python tools/lab.py check 03
```

`start` 在 `work/03-figures` 放置起始工程。使用任意编辑器修改它；本地核验需要 Python 和相应 TeX 工具，不限定编辑器。PDF 文本与元数据取证使用 `pdftotext` 和 `pdfinfo`；`doctor` 会列出工具状态，缺少它们时相关项目显示为 `unavailable`，即使编译本身成功也不会自动补成通过。

`check` 会复制工程到 `_build/` 的独立目录后实际构建，保留日志、`check-report.json`、`check-report.html` 和 `ai-review-prompt.txt`，构建成功时保留本次 PDF，并更新 `reports/latest-03.json`。打开 HTML 报告可逐项查看证据；在离线手册导入 JSON 后，页面显示具体项目：

|结果|含义|下一步|
|---|---|---|
|`pass`|本次检查找到了支持该技术条件的证据|继续看其他检查项、理解题与 PDF|
|`fail`|本次检查发现不符合条件的结果|按证据和提示修改，再核验|
|`unavailable`|缺少所需工具或证据，无法完成该项检查|查看缺失原因，补齐后重跑；或明确改用 AI 辅助路线|

报告的整体状态为 `passed`、`needs_work` 或 `blocked`，与上表的单项状态分别显示。主关自动核验进度只采用 `check_scope='lab'` 的完整报告；单纯 `build` 或支线入口的报告只提供该入口的构建证据。由于它们也会更新同一关的 `latest-XX.json`，运行支线后应重跑主入口，例如 `python tools/lab.py check 06`，再导入报告。

报告对应运行时的源码副本。继续修改后，需要重新运行并导入新报告；旧报告不能证明新源码的状态。若采用不同但合法的写法遇到静态规则误报，可结合日志、源码和 PDF 记录原因，不必为匹配规则改坏工程。

## 路线二：在线平台与 AI 辅助核对

可以继续使用 Overleaf 或其他在线工具。上传对应 `downloads/` 起始包，保留相对目录，选择主文件和编译器，完成任务后下载源码、当前 PDF 与编译日志。

若本地有 TeX 环境，下载并解压后运行：

```text
python tools/lab.py check 03 --project "下载并解压的工程目录"
```

若没有本地环境，使用手册里的本关 AI 核验请求，向所选模型提供上述真实文件。让模型依据源码与日志定位问题，依据实际 PDF 说明可见结果，缺什么就记为未确认。记录 AI 结论、具体证据和仍待检查的内容，再自己试改和重新编译。

AI 辅助记录与自动报告是不同的证据来源。没有运行检查器，不会出现本地自动通过；模型说“正确”不能替代实际构建，也不能证明其没有看过的 PDF 版式正确。

## 理解题、PDF 自查与变式

每关有两道理解或预测题，提交后可看到答案解释。答错时，回到对应源码做一次小修改验证，然后再回答。答案可见、自查可自行勾选，因此这些记录只帮助自学定位薄弱处，不是考试或学习效果测量。

每关还有两项明确的 PDF 自查。只对自己实际打开并核对的输出勾选，未做的保持未确认。选择本地自动路线或 AI 辅助路线，都需要这两步。

变式在副本中操作：先写预测，改变章节顺序、图片尺寸、文献顺序或数据，真实构建并对照变化。完成后恢复最终版本。可以用 `REPORT.md` 留笔记，也可以使用自己的笔记工具；无需提交给任何人。

## 遇到问题时

先读报告的失败项和真实日志，再按需打开提示。本次 `_build/` 目录中的 `ai-review-prompt.txt` 已整理任务、检查结果、真实命令和日志、源码及 PDF 文本摘录，也可从 HTML 报告复制。摘录会按长度限制截断，不代表已提供完整工程；PDF 文本不包含视觉排版证据。按问题补充原始源码、完整日志和实际 PDF，要求智能体解释证据、指出缺失信息、给局部提示并让你试改，详见 [AI 工作流](AI-WORKFLOW.md)。参考解用于对照差异，不是唯一合法写法。

页面进度区分自动核验与 AI 辅助记录。它表示你已完成哪些检查动作，不表示模型或工具证明了你已经学会。最终源码、PDF、日志与记录都由自己保留。
